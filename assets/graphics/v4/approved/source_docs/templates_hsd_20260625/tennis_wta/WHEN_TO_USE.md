# HSD Tennis / WTA — Final Cleanup When-to-Use Notes

## Variant A — Match Result / Match Preview Card
Use for WTA match results or previews when the core post is player vs opponent, round, tournament, and either a scoreline or next-match context.

## Variant B — Tournament Story / Advancement Card
Use for advancement stories, title runs, upset stories, seed stories, milestones, bracket movement, and broader tournament moments.

## Variant C — Story / Vertical Tennis Update
Use for quick vertical Stories/Reels updates. Supported modes:
1. Match result + question
2. Next match preview + question
3. Tournament story update + why it matters
4. Player spotlight + poll/question

## Production reminders
- Use the official compact HSD badge exactly as uploaded.
- Use approved player images and approved tournament/event logos only.
- Use `APPROVED TOUR / EVENT LOGO SLOT` when no approved logo is provided.
- Abstract tennis textures are allowed as design backgrounds.
- Public mockups stay clean and publish-ready.
- Do not invent scores, opponents, tournament names, rounds, records, quotes, injuries, rankings, or stats.
