# LAST NIGHT IN THE W — When to Use

## Variant A — Multi-game Feed / Threads recap
Use when you need one strong feed or Threads recap image for a WNBA slate with about 3 to 5 completed games. One lead result gets the main emphasis, followed by supporting results and an optional takeaway or question.

## Variant B — Story rolling recap
Use when you need a vertical, fast-scanning recap for Stories or Reels. Best for multiple finals, quick consumption, and a simple bottom takeaway or CTA.

## Variant C — Carousel cover / recap package
Use when the slate deserves a full swipeable package. The cover can use one of three allowed bottom-area modes, followed by a featured final slide, a multi-game recap slide, and an engagement-focused end-question slide.

## Global notes
- Public-facing graphics use the official compact HSD badge only, top-left.
- Keep the badge small and secondary to the content.
- Use approved team logo slots only in blank layouts.
- Use clean score placeholders like 00–00 or SCORE SLOT.
- Keep public mockups free of internal labels, variant labels, spec-sheet labels, and production notes.
