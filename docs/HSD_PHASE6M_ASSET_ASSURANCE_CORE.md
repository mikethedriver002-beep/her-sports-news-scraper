# HSD Phase 6M — Asset Assurance Core

## Objective

Phase 6M ends the missing-asset patch loop by separating two states:

- **Render-safe:** HSD can always produce a truthful, clean graphic.
- **Live-ready:** the exact render hash has passed technical gates and human visual approval.

A missing logo or player image is no longer allowed to drop an event or crash the renderer.

## Team asset resolution

1. Verified decodable exact logo.
2. Verified official fallback logo.
3. Clearly labelled HSD team badge built from the verified team name and available colors.

The HSD badge is not presented as an official logo. It enters the review lane and remains bound to exact-hash human approval.

## Player asset resolution

1. Verified decodable player asset.
2. Fixture reference only in fixture mode.
3. A non-player **TEAM SPOTLIGHT** card.

The fallback never invents a face, body, jersey, statistic, or athlete identity.

## Multi-sport foundation

The shared catalog includes:

- WNBA — active renderer integration
- NWSL — bootstrap ready
- USWNT — bootstrap ready
- Women's tennis — bootstrap ready
- LPGA — bootstrap ready
- NCAA softball — bootstrap ready
- Women's volleyball — bootstrap ready

Each sport receives a registry template and an HSD fallback template from the same core. Future sport phases add feeds and templates without rebuilding asset safety from scratch.

## Safety

- Free sources only.
- Human visual approval remains mandatory.
- Production cutover remains false.
- Auto-publish remains false.
- No fake players or unofficial assets masquerading as official marks.
