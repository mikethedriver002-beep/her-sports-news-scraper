# HSD Graphics Template Master Batch Prompts v1

Use these prompts in the Her Sports Daily Graphics Production chat. Build the first six as priority. LPGA is included as the immediate seventh priority.

## Global instruction for every template build

HSD TEMPLATE BUILD.

You are building premium Her Sports Daily template systems, not one-off graphics.

Global brand law:
- Public-facing graphics use the official compact HSD badge only, top-left.
- Do not use the full HSD + HER SPORTS DAILY lockup on public graphics.
- Do not recreate the logo as text.
- Do not add HER SPORTS DAILY beside the badge.
- One HSD watermark only.
- No fake athletes, fake jerseys, fake kits, fake logos, or invented stats.
- Use approved logos and approved player photos only.
- If no approved player photo exists, use a text fallback such as KEY MATCHUP, WATCH POINT, WHY IT MATTERS, or PLAYER SPOTLIGHT TEXT.
- Use dark cinematic sports-media style, high contrast, bold condensed hierarchy, premium editorial feel.
- Social-first readability only.
- All critical text must stay inside safe zones.
- Every template must include a real JSON layout spec file, not a screenshot of code.

Deliver for each template direction:
1. Finished template mockup PNG.
2. Blank/editable layout reference PNG.
3. Machine-readable layout spec as real JSON.
4. Short when-to-use guidance.
